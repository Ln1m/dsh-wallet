# dsh-wallet 介绍视频脚本

> 时长约 3 分钟，手机竖屏或电脑横屏均可。节奏：每个功能一个镜头，画面 + 旁白 + 字幕。

---

## 一、录制准备

| 项 | 准备 |
| --- | --- |
| 软件 | DSH 桌面端（已装好 dsh-wallet 插件） |
| 录屏 | OBS / Windows 自带录屏（Win+G）/ 剪映录屏 |
| 声音 | 安静环境 + 麦克风；或后期配音 |
| 字幕 | 后期用剪映「文稿匹配」或手动加 |
| 账号 | 一个已配置 `DEEPSEEK_API_KEY` 的 DSH（余额能查出来） |

**演示前确认**：左栏展开（能看到底部钱包面板）、余额能查到、`本会话消耗` 有数值（先随便发几句话产生消耗）。

---

## 二、分镜脚本

### 镜头 0 · 开场（0:00–0:10）

- **画面**：DSH 界面全景，鼠标移到左栏底部「DeepSeek 钱包」面板上晃一下（高亮）。
- **动作**：无操作，只展示。
- **旁白**：
  > 大家好，这是一个 DeepSeek Harness 插件 —— dsh-wallet。它能让你在 DSH 里直接看 DeepSeek 余额、会话消耗成本，还能一键充值。

---

### 镜头 1 · 余额显示（0:10–0:35）

- **画面**：聚焦左栏底部钱包面板，依次指到：绿色状态点 → 「余额 CNY」数字 → 右上角「↻」刷新按钮。
- **动作**：点一下「↻」，展示余额刷新。
- **旁白**：
  > 左栏底部这块就是钱包面板。它自动读取你 DSH 里配置的 API Key，每 30 秒查一次官方余额接口，CNY、USD 双余额池都支持。右上角这个刷新按钮可以手动立即刷新。

---

### 镜头 2 · 本会话消耗 + 悬停明细（0:35–1:05）

- **画面**：指到「本会话消耗 ¥xx」这行，鼠标**悬停**在金额上，弹出明细小窗（输入 / 缓存命中 / 输出的 token 数和金额）。
- **动作**：悬停 2 秒，让弹窗展示清楚；再移开鼠标。
- **旁白**：
  > 更有用的是「本会话消耗」——它用 token 实际用量乘官方价格，实时估算你当前这个对话已经花了多少钱。把鼠标悬停在金额上，能看到输入、缓存命中、输出各自的 token 量和金额明细。

---

### 镜头 3 · 峰谷计价标注（1:05–1:30）

- **画面**：指到「本会话消耗」旁边的小胶囊标注（「基础价」或「高峰价 / 空闲价」）。
- **动作**：无操作，指着说明。
- **旁白**：
  > 注意旁边这个小标签。DeepSeek 从 8 月 17 号开始采用峰谷定价，高峰时段价格是空闲时段的两倍。插件内置了官方价格表，会按北京时间自动判断当前是基础价、高峰价还是空闲价，所以你看到的消耗金额是实时准确的。

---

### 镜头 4 · 低余额告警（1:30–1:45）

- **画面**：指到「⚠ 余额偏低，建议充值」红色提示（如果当前余额高，用文字说明，不硬演）。
- **动作**：无操作。
- **旁白**：
  > 当人民币余额低于 10 元、或美元低于 2 美元时，面板会标红提醒你该充值了，不会用到一半才发现余额不足。

---

### 镜头 5 · 一键充值（1:45–2:15）

- **画面**：点「充值」按钮 → DSH 窗口内弹出官方充值页（16:9 无边框弹窗，只有充值内容，没有浏览器地址栏和多余导航）。
- **动作**：点充值 → 展示弹窗 → 鼠标点一下 DSH 主窗口，弹窗自动关闭。
- **旁白**：
  > 点「充值」，它会直接在 DSH 窗口里打开官方的充值页面——注意这不是弹系统浏览器，而是一个干净的 16:9 内嵌窗口，只显示充值内容。点一下外面，窗口就自动关掉了，很轻量。

---

### 镜头 6 · 用量与 API Key 入口（2:15–2:40）

- **画面**：先点「明细」，弹窗切到官方用量页；再点「API Key」，弹窗**直接切换**到 API Key 管理页（不重新开窗）。
- **动作**：点「明细」→ 点「API Key」，展示流畅切换。
- **旁白**：
  > 「明细」打开的是官方用量统计页，「API Key」打开的是官方 Key 管理页。它们共用同一个内嵌窗口，来回切换很流畅，不会开一堆窗口。

---

### 镜头 7 · 问 AI 也能查余额（2:40–3:00）

- **画面**：在对话输入框输入「DeepSeek 余额还剩多少？」发送，AI 调用 `query_deepseek_balance` 工具返回余额摘要。
- **动作**：输入并发送，展示 AI 回复。
- **旁白**：
  > 这个插件还注册了一个工具，你可以直接在对话里问「余额还剩多少」，AI 会帮你查好并回答，不用手动点面板。

---

### 镜头 8 · 安装与开源（3:00–3:15）

- **画面**：切到 GitHub 仓库页（Ln1m/dsh-wallet）和 npm 包页，指到安装命令 `dsh plugin add dsh-wallet`。
- **动作**：展示页面。
- **旁白**：
  > 它已经开源在 GitHub、也发布到了 npm。一条命令 `dsh plugin add dsh-wallet` 就能装，重启后左栏底部就会出现这个钱包面板。欢迎 Star 和提建议。

---

### 镜头 9 · 结尾（3:15–3:25）

- **画面**：回到 DSH 全景，钱包面板在左栏底部。
- **动作**：无操作。
- **旁白**：
  > 以上就是 dsh-wallet 的全部功能。谢谢观看，我们下个视频见。

## 四、录制小贴士

1. **录屏前**：先关掉其它无关窗口、通知，桌面整洁；DSH 切到深色或浅色统一主题。
2. **鼠标强调**：用剪映或 OBS 的「鼠标高亮/点击波纹」让观众看清你在点哪里。
3. **节奏**：每个功能停顿 1–2 秒再切下一个镜头，方便后期剪辑。
4. **卡顿处理**：弹窗打开/切换的瞬间是最容易卡或闪的，录的时候如果闪一下，后期剪掉那一两帧即可。
5. **配乐**：可选轻 BGM，音量低于人声。
6. **封面**：截一张钱包面板的特写（`assets/screenshot-panel.png` 可直接用）加标题。
